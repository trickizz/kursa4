# 🏆 Конкурс проектов — платформа для проведения конкурсов

[![tests](https://github.com/trickizz/kursa4/actions/workflows/tests.yml/badge.svg)](https://github.com/trickizz/kursa4/actions/workflows/tests.yml)

Курсовой проект на **Django 5**: полноценная система проведения конкурсов проектов
с ролевой моделью, экспертизой, наставничеством, командами, голосованием,
уведомлениями, достижениями и аналитикой.

## ✨ Возможности

- **Конкурсы**: обложки, этапы с дедлайнами (таймлайн, подсветка просроченных),
  критерии оценки, контроль сроков приёма (после дедлайна подача закрыта).
- **Проекты**: обложки, жизненный цикл (черновик → подача → экспертиза → отбор →
  работа → завершение), документы, **команды соавторов** (приглашения по логину).
- **Экспертиза**: организатор закрепляет экспертов за проектом, прогресс
  «оценено N/M критериев», валидация (балл ≤ максимума, без дублей, нельзя
  оценивать проект своей команды и критерий чужого конкурса).
- **Честный балл**: оценка считается как средний **% от максимума** по критериям.
- **Голосование**: 1 пользователь = 1 голос (повторный клик снимает), нельзя
  голосовать за проект своей команды и за черновики.
- **Комментарии**: ветки ответов + **@упоминания** с уведомлениями, AJAX, защита от XSS.
- **Уведомления**: колокольчик в шапке — смена статуса, новые оценки/комментарии,
  назначения, приглашения в команду, достижения.
- **Итоги и лидерборд**: рейтинг по баллу и голосам, подиум топ-3, кнопка
  «Подвести итоги» (закрывает конкурс, завершает отобранные проекты, награждает
  победителя), **PDF-протокол** результатов (кириллица).
- **Достижения**: 8 ачивок (дебют, первая оценка, победитель и др.), **рейтинг участников**.
- **История статусов**: журнал «кто/когда/что изменил» на странице проекта.
- **Дашборд**: графики Chart.js, статистика по ролям, экспорт/импорт CSV (кэш 60 с).
- **Профиль**: роль, возможности, достижения, личная статистика.
- **REST API** (DRF) + **Swagger** (`/api/docs/`), токен-авторизация.
- **Дизайн «Aurora»**: градиенты, карточки, бейджи, анимации, адаптив,
  **тёмная тема** (переключатель), drag-and-drop загрузка файлов.
- **Восстановление пароля** по email, админ-панель с темой Jazzmin.
- **Качество**: 49 автотестов, CI (GitHub Actions), ruff, coverage, Docker + PostgreSQL.

## 👥 Роли — чем они реально отличаются

Роль = группа Django, у пользователя одна основная роль. **Админ наследует права всех ролей.**

| Возможность | Участник | Наставник | Эксперт | Организатор | Админ |
|---|:---:|:---:|:---:|:---:|:---:|
| Создать проект / подать на конкурс, команда | ✅ | — | — | — | ✅ |
| «Мои подопечные», документы подопечных | — | ✅ | — | — | ✅ |
| Оценки по критериям, «Мои оценки» | — | — | ✅ | — | ✅ |
| Конкурсы, этапы, критерии, статусы | — | — | — | ✅ | ✅ |
| Назначение экспертов и наставников, итоги, PDF | — | — | — | ✅ | ✅ |
| Дашборд, экспорт/импорт CSV | — | — | — | ✅ | ✅ |
| Назначение ролей («Роли»), админ-панель | — | — | — | — | ✅ |
| Голоса, комментарии, уведомления, достижения | ✅ | ✅ | ✅ | ✅ | ✅ |

При регистрации доступны: **Участник**, **Наставник**, **Эксперт**.
**Организатора** и **Администратора** назначает админ на странице `/roles/`.

## 🚀 Быстрый запуск

```bash
pip install -r requirements.txt
python3 manage.py migrate
python3 manage.py seed_demo      # демо-данные (по желанию)
python3 manage.py runserver
```

Откройте http://127.0.0.1:8000/

## 🐳 Docker (PostgreSQL)

```bash
docker compose up --build
```

Поднимает PostgreSQL 16 + веб-сервер (gunicorn), применяет миграции и демо-данные.
Сайт: http://localhost:8000/. Настройки — через переменные окружения (см. `.env.example`).

## 🔌 REST API

- Swagger UI: **`/api/docs/`**, схема: `/api/schema/`
- Эндпоинты: `/api/contests/`, `/api/projects/`, `/api/evaluations/`, `/api/me/`
- Действия: `GET /api/contests/{id}/results/`, `POST /api/projects/{id}/vote/`,
  `POST /api/projects/` (создание черновика участником)
- Токен: `POST /api/token/` (username/password) → заголовок `Authorization: Token <key>`

```bash
curl -X POST http://127.0.0.1:8000/api/token/ -d "username=student&password=Demo12345!"
curl http://127.0.0.1:8000/api/me/ -H "Authorization: Token <ваш_токен>"
```

## 🆕 Спринт 2 — доведено до продакшен-качества

**Целостность и безопасность**
- Голоса и оценки **замораживаются** после подведения итогов; результаты фиксируются в **снапшоте** (рейтинг больше не «плывёт»).
- **Гейт полноты**: итоги можно подвести, только когда каждый проект оценён по всем критериям (и всеми закреплёнными экспертами).
- **Инвалидация кэша** дашборда по сигналам (данные всегда свежие).
- **Безопасная отдача медиа**: whitelist расширений, `Content-Disposition: attachment` для не-изображений, `X-Content-Type-Options: nosniff`, защита от path traversal.
- **Модерация комментариев**: редактирование/удаление своих, удаление организатором.
- **Тосты** вместо `alert()`, кастомный скроллбар, доработана тёмная тема.

**Новые возможности**
- **Веса критериев** → взвешенный итоговый балл (%).
- **Апелляции**: участник оспаривает оценку → организатор удовлетворяет/отклоняет с комментарием.
- **Теги проектов** + фильтр по тегам + сортировка (новые/старые/голоса/балл).
- **Дублирование конкурса** (с этапами и критериями) одним кликом.
- **Массовые действия**: смена статусов / назначение эксперта пачкой (чекбоксы).
- **Чек-лист наставника**: задачи подопечному проекту с отметкой выполнения.
- **Email-уведомления** (SMTP/console) + **напоминания о дедлайнах**.
- **Real-time (SSE)**: живой счётчик уведомлений в шапке.
- **XLSX-экспорт** (проекты + оценки, styled) и **превью документов** (PDF/изображения inline).
- **Миниатюры обложек** (автогенерация Pillow) — карточки грузят лёгкие превью.

**Инженерия**
- `/healthz` (healthcheck для Docker) + структурированное **логирование**.
- **DRF**: throttling (anon 60/min, user 240/min) + **django-filter** (фильтрация в API).
- **CI**: сборка Docker-образа, **динамический бейдж покрытия** (авто-коммит), dependabot.
- Команды: `close_expired` (автозакрытие по cron), `send_deadline_reminders`, `backup` (дамп данных).
- **117 автотестов**, покрытие ~96%, ruff.

### Cron-команды

```bash
python3 manage.py close_expired            # закрыть конкурсы с истёкшим дедлайном
python3 manage.py send_deadline_reminders  # напомнить о дедлайнах (<= 3 дней)
python3 manage.py backup                   # дамп данных в backups/
```

### Новые API-возможности

```bash
curl "/api/projects/?contest=1&status=submitted&ordering=-votes"
curl "/api/contests/?is_active=true"
```

## 🔧 Спринт 3 — доведено до продакшен-качества

**Исправленные дыры**
- **Тосты вместо `alert()`**: единый `showToast()` + стек тостов (светлая/тёмная тема) —
  ошибки и успехи голоса/комментария/статуса больше не теряются.
- **Live-уведомления (SSE)**: счётчик в колокольчике и новые уведомления обновляются
  без перезагрузки (`EventSource` → `/notifications/stream/`).
- **Паритет API с вебом**: голосование через API блокируется после подведения итогов;
  `contests/{id}/results/` отдаёт **замороженный снапшот** и **взвешенный** балл.
- **Рейтинг без N+1**: агрегация одним запросом (+ исправлен баг умножения голосов
  на число достижений из-за join); кэш рейтинга инвалидируется сигналами.
- **Безопасность медиа**: inline только для растровых картинок и PDF (SVG — attachment),
  `nosniff`, CSP для inline-изображений, экранирование имени файла.
- **PDF-протокол**: нормальный текстовый шрифт **DejaVu Sans** (обычный + жирный),
  бренд-шапка, итоговая таблица из снапшота, **разбивка по критериям**, блок подписей и дата.
- **Модерация комментариев**: инлайн-редактирование вместо `prompt()`.
- **Тёмная тема**: подсветка непрочитанных уведомлений (`.notif-unread`).

**Инженерия**
- `/healthz` как **healthcheck web-сервиса** в docker-compose + том `backups`.
- Логи `fontTools` приглушены до WARNING.
- Гигиена репозитория: из git убраны `.coverage`, `.ruff_cache/` и дампы `backups/`
  (содержали хэши паролей), починен `.gitignore`.
- **+43 теста** (паритет API, рейтинг, медиа-безопасность, PDF, троттлинг, SSE, CRUD организатора, команда, CSV, seed_demo) — всего **117**, покрытие **96%**.
