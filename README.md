# 🏆 Конкурс проектов — платформа для проведения конкурсов

Курсовой проект на **Django 5**: полноценная система проведения конкурсов проектов
с ролевой моделью, экспертизой, наставничеством, голосованием и аналитикой.

## ✨ Возможности

- **Конкурсы**: создание, редактирование, этапы с дедлайнами (таймлайн), критерии оценки.
- **Проекты**: черновик → подача → экспертиза → отбор → работа → завершение;
  загрузка документов, комментарии (AJAX, без перезагрузки), голоса.
- **Экспертиза**: оценки по критериям конкурса с валидацией (балл не выше максимума,
  без дублей, нельзя оценивать свой проект и критерий чужого конкурса).
- **Наставничество**: организатор назначает наставника проекту, у наставника
  есть раздел «Мои подопечные» и право загружать документы подопечным.
- **Голосование**: 1 пользователь = 1 голос (повторный клик снимает голос),
  нельзя голосовать за свой проект и за черновики.
- **Дашборд**: графики Chart.js (статусы проектов, топ конкурсов), статистика
  по ролям, экспорт проектов и оценок в CSV, импорт проектов из CSV.
- **Профиль**: роль, её возможности, личная статистика и активность.
- **Современный дизайн**: дизайн-система «Aurora» (градиенты, карточки, бейджи
  ролей и статусов, анимации, адаптивная вёрстка, Bootstrap 5 + Bootstrap Icons).
- **Админ-панель** Django с темой Jazzmin (опционально).

## 👥 Роли — чем они реально отличаются

Роль = группа Django. У пользователя одна основная роль; меню, страницы и права
зависят от неё. **Администратор наследует права всех ролей.**

| Возможность | Участник | Наставник | Эксперт | Организатор | Админ |
|---|:---:|:---:|:---:|:---:|:---:|
| Создать проект / подать на конкурс | ✅ | — | — | — | ✅ |
| Редактировать свой черновик, загружать документы | ✅ | — | — | — | ✅ |
| «Мои подопечные», документы и комментарии подопечных | — | ✅ | — | — | ✅ |
| Выставлять оценки по критериям, «Мои оценки» | — | — | ✅ | — | ✅ |
| Создавать конкурсы, этапы, критерии | — | — | — | ✅ | ✅ |
| Менять статусы проектов, назначать наставников | — | — | — | ✅ | ✅ |
| Дашборд, экспорт/импорт CSV | — | — | — | ✅ | ✅ |
| Назначать роли пользователям (страница «Роли») | — | — | — | — | ✅ |
| Админ-панель Django | — | — | — | — | ✅ |
| Голосовать и комментировать | ✅ | ✅ | ✅ | ✅ | ✅ |

- При регистрации можно выбрать: **Участник**, **Наставник**, **Эксперт**.
- **Организатора** и **Администратора** назначает админ на странице **«Роли»**
  (`/roles/`) или через админ-панель. Смена роли сразу меняет меню и права.
- Ролевые группы создаются автоматически миграцией `0003_create_role_groups`.

## 🚀 Запуск

```bash
pip install -r requirements.txt
python3 manage.py migrate
python3 manage.py seed_demo      # демо-данные (по желанию)
python3 manage.py runserver
```

Откройте http://127.0.0.1:8000/

### Демо-аккаунты (после `seed_demo`)

| Логин | Пароль | Роль |
|---|---|---|
| `admin` | `Admin12345!` | Администратор (суперпользователь) |
| `organizer` | `Demo12345!` | Организатор |
| `expert`, `expert2` | `Demo12345!` | Эксперты |
| `mentor` | `Demo12345!` | Наставник |
| `student`, `student2` | `Demo12345!` | Участники |

Без `seed_demo` создайте суперпользователя: `python3 manage.py createsuperuser`.

## ✅ Тесты

27 автотестов покрывают роли и права, жизненный цикл проекта, голосование,
оценки, документы, наставничество, AJAX и CSV:

```bash
python3 manage.py test contests
```

## 🗂 Структура

```
contests/
├── models.py            # Contest, Stage, Project, Criterion, Evaluation,
│                        # Comment, Document, ProjectVote
├── roles.py             # единая ролевая модель (группы, проверки, set_role)
├── context_processors.py# флаги ролей во всех шаблонах
├── mixins.py            # ролевые миксины доступа
├── views.py             # страницы, AJAX (голоса/статусы/комментарии), роли, CSV
├── forms.py             # формы с валидацией (оценки, регистрация, наставник…)
├── utils.py             # экспорт/импорт CSV
├── tests.py             # 27 автотестов
├── management/commands/seed_demo.py
├── migrations/          # в т.ч. создание ролевых групп и ProjectVote
└── templates/           # дизайн «Aurora»: base, home, конкурсы, проекты,
                         # дашборд, профиль, роли, auth
static/css/style.css     # дизайн-система
```
